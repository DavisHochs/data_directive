# Agent Guidelines

When making changes to this repository:

1. Always align changes with the goals in PROJECT_GOAL.md
2. Prefer simple, explicit implementations over clever abstractions
3. Do not introduce new technologies unless explicitly instructed
4. If a change adds complexity, explain why it supports the project goal
5. Assume this project may be shown in a portfolio later

If a request conflicts with project goals:
- Flag the conflict
- Propose a minimal alternative
